

\# Enterprise Agentic RAG Assistant



An enterprise-focused Agentic RAG chatbot with conversational memory and input guardrails.



\## Features



\- Agentic RAG using LangGraph

\- Qdrant semantic search

\- Conversational memory

\- NeMo Guardrails

\- Groq LLM

\- Portkey

\- FastAPI

\- Streamlit

\- Logfire



\## Tech Stack



Python • LangGraph • Qdrant • Groq • Portkey • NeMo Guardrails • FastAPI • Streamlit • Logfire
